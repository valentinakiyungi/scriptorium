      Settings

      Scriptorium uses Google Gemini. Create a free key at aistudio.google.com/apikey. It is saved to the .env file on this computer and never leaves it except in requests to Google.

      Free keys allow about 20 requests per model per day; one document uses roughly 12–25. Scriptorium moves to another model when one runs out. For heavier use, enable billing in AI Studio — limits rise immediately and a document typically costs a few cents.

      How Scriptorium works

      A LangGraph Supervisor-Worker pipeline. The supervisor never writes — it decides who works next and when the document is good enough.

      The agent team

      1. Planner outlines the document for its type and writes sharp research questions.
      2. Researchers answer every question in parallel using Gemini with Google Search grounding, plus any reference sources you attached.
      3. Collator merges and de-duplicates all sources into one numbered registry.
      4. Writers draft every section in parallel, citing only real sources.
      5. Assembler removes invalid citations, renumbers them and builds the references.
      6. Reviewer scores the draft against the rubric. Below the pass score, the supervisor researches the gaps and sends writers back to revise.

      Tips

      • Be specific: “EU offshore wind costs since 2020 for a finance audience” beats “wind power”.
      • Attach reference sources to ground the document in your own material. Turn off Live web to use only them.
      • More questions = broader evidence; more revisions = more polish. Both take longer.
      • Every run is saved to the output/ folder and listed under History.

      Shortcuts

      • ⌘/Ctrl + Enter — draft  ·  Esc — close dialogs

      Command line

      • npm run draft -- "your topic" --type policy-memo
      • npm run bench — benchmark all document types
